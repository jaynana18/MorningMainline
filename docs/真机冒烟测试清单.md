## 一、本轮改动对应的四条（重点看这个）

| # | 测什么 | 怎么做 | 期望 |
|---|---|---|---|
| 1 | 🔴 **点系统通知不再闪退** | 让 App 退到后台（或锁屏），等一条提醒弹成系统通知，**点它** | App 正常打开并跳到对应页面，**不闪退**。连点两三次都不崩 |
| 2 | 🔴 **播报开关能关** | 个人中心 → 提醒设置 → 取消勾选「应用内语音播报」 | 之后提醒**只弹窗、不出声**。再勾回来，声音恢复 |
| 3 | 🔴 **播报时间与页面一致** | 让一个任务超时，对比弹窗里的语音和页面「已超 N 分钟」 | 两个数字**完全相同**（比如页面写「已超 2′」，语音也是「延误 2 分钟」） |
| 4 | 开关是常驻的 | 关掉开关 → 杀掉 App 重开 → 看个人中心 | 开关**仍是关的**（说明存住了，不是每次重来） |

## 二、语音播报（上一轮功能，回归确认）

| # | 测什么 | 怎么做 | 期望 |
|---|---|---|---|
| 5 | 🔴 亮屏也能听到 | 屏幕亮着、App 在前台，等一条提醒到点 | 弹窗出现的同时**念出来** |
| 6 | 🔴 耳机里也念 | 连上蓝牙耳机（AirPods 等），重复上一条 | 声音从**耳机**出来，不是手机扬声器 |
| 7 | 念的是「现在几点」 | 听语音开头 | 是「现在是 X 点 Y 分」，**是当下时刻**，不是提醒本来该响的时刻 |
| 8 | 连播不叠音 | 让两条提醒接连弹（或超时循环每 2 分钟一轮） | 后一句**掐掉**前一句，不会两句话叠在一起听不清 |
| 9 | 后台不出声（设计如此） | 切到桌面/别的 App，等提醒到点 | 走**系统通知**，App 不出声。回到 App 看到弹窗才出声 |
| 10 | 别人的音乐只被压低 | 后台放歌/播客，同时触发一条播报 | 念的时候音乐**变小但没停**，念完**音量恢复**。不会一直闷着 |
| 11 | 队列不抢播 | 让两条提醒同时到点（当前那条还没关） | 只念**屏幕上正在显示**的那一条；关掉它、下一条上来时才念 |

> **关于「边看视频边播报」**：不是两个声音同时出现。系统会把视频声音**压低**，念完恢复。
> 如果视频里有**人说话**（播客/有声书），会被**打断**（因为两段语音叠一起听不清）。
> 正在打电话时，播报**可能完全发不出来** —— 这是 `AVAudioSession` 的系统规则，App 改不了。

## 六、怎么装

1. **重新构建前端**（改了 `web/` 就必须做）：
   ```bash
   cd web && npm run build
   ```
   > 如果报 `SAFE_DELETE_BULK_GUARD_ERROR`，先把旧目录挪走再 build：
   > `mv dist /tmp/mm-dist-old && npm run build`

2. **用 Xcode 打包装机**：打开 `MorningMainline.xcodeproj`，选你的 iPhone 13 Pro Max，Run（⌘R）。
   - 免费个人 Team 签名即可，**不需要付费账号**。
   - ⚠️ 每次 `xcodegen generate` 会清掉 scheme 的环境变量（`COSMO_MIND_API_KEY`），需要手动补回。

3. **装不上 / 提示无法安装**：
   - 确认 `CFBundleVersion` 已 +1（现在是 **5**）。iOS **不允许**同版本同构建号重复安装。
   - 改构建号要**四个** `Info.plist` 一起改：`iOS/`、`iOSWidget/`、`Watch/`、`WatchWidget/`。

## 七、当前的已知边界（不是 bug，别当问题测）

| 现象 | 说明 |
|---|---|
| 后台不播报声音 | 设计如此。App 挂起后没有任何东西能触发 `speak()`，而且系统不允许后台**启动**新播放。后台走系统通知 |
| 系统「播报通知」亮屏不念 | iOS 只对锁屏/熄屏生效，App 改不了。所以才做了 App 内播报 |
| 突破专注模式失效 | `timeSensitive` 是需要付费账号的 capability，免费个人 Team 用不了，已摘除。升级账号后**无需改代码**即自动生效 |
| 手表装不上 | Xcode 26.6 只支持到 watchOS 26.5，而手表是 watchOS 27。**工具链版本代差**，不是代码问题，需先升 macOS + Xcode 27 |
| 浏览器里没有手表同步 | 浏览器宿主没有 `WCSession`，物理上做不到跨设备共享 |
| 「已超 N 分钟」取整 | 一律**向下取整**（2 分 59 秒 = 2 分钟）。这是刻意统一的，不要以为该进位 |
