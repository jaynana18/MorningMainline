## 六、怎么装

1. **重新构建前端**（改了 `web/` 就必须做，且**必须早于**打包）：
   ```bash
   cd web && npm run build
   ```
   > 如果报 `SAFE_DELETE_BULK_GUARD_ERROR`，先把旧目录挪走再 build：
   > `mv dist /tmp/mm-dist-old && npm run build`
   >
   > ⚠️ 顺序反了（先打包后 build）**不会报错**，只是包里还是旧 UI。
   > 核对方法：比对包内 `dist/assets/index-*.js` 的文件名与 `web/dist/assets/` 是否一致。

2. **用 Xcode 打包装机**：打开 `MorningMainline.xcodeproj`，选 iPhone 13 Pro Max，Run（⌘R）。
   - 免费个人 Team 签名即可，**不需要付费账号**。
   - ⚠️ 每次 `xcodegen generate` 会清掉 scheme 的环境变量（`COSMO_MIND_API_KEY`），需要手动补回。

3. **装不上 / 提示无法安装**：
   - 确认 `CFBundleVersion` 已 +1（现在是 **6**）。iOS **不允许**同版本同构建号重复安装。
   - 改构建号要**四个** `Info.plist` 一起改：`iOS/`、`iOSWidget/`、`Watch/`、`WatchWidget/`。

## 七、当前的已知边界（不是 bug，别当问题测）

| 现象 | 说明 |
|---|---|
| 🔴 **系统通知弹窗不播报声音** | **iOS 硬边界，App 改不了**。系统通知弹出时 App 已在后台被挂起，`AVSpeechSynthesizer` **无法启动新播放**（系统只允许「已经在播的」继续播）。要「亮屏/后台也念」，只能走 App 内播报（前台）或「预合成音频文件 + 自定义通知音」那条路（工作量大，未采用） |
| 系统「播报通知」亮屏不念 | iOS 只对锁屏/熄屏生效。所以才做了 App 内播报 |
| 突破专注模式失效 | `timeSensitive` 是需要付费账号的 capability，免费个人 Team 用不了，已摘除。升级账号后**无需改代码**即自动生效 |
| 手表装不上 | Xcode 26.6 只支持到 watchOS 26.5，而手表是 watchOS 27。**工具链版本代差**，需先升 macOS + Xcode 27 |
| 浏览器里没有手表同步 | 浏览器宿主没有 `WCSession`，物理上做不到跨设备共享 |
| 「已超 N 分钟」取整 | 一律**向下取整**（2 分 59 秒 = 2 分钟）。刻意统一，不要以为该进位 |
| 超时提醒默认仍是 2 分钟 | 默认值刻意保持「全程 2 分钟」，老用户升级后节奏**不变**；要「越拖越密」得自己去个人中心设 |
